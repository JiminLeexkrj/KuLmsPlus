# KU LMS+ 캘린더

고려대학교 LMS(mylms.korea.ac.kr)의 마감 일정을 한 달짜리 캘린더로 모아 보여주는 크롬 확장 프로그램입니다.
LMS 기본 캘린더에는 나오지 않는 **온라인 강의의 출석인정, 지각인정, 열람 기간**도 함께 보여줍니다.

> 학교와 관계없는 비공식 도구입니다.

## 볼 수 있는 것

- 과제, 퀴즈, 수업 일정
- 온라인 강의의 출석 마감, 지각 마감, 열람 종료일
- 앞으로 14일 안에 남은 마감 목록 (D-day 표시)
- 이미 본 강의와 제출한 과제는 완료로 표시

## 설치 방법

1. **[KU-LMS-Plus.zip 다운로드](https://github.com/JiminLeexkrj/KuLmsPlus/raw/main/KU-LMS-Plus.zip)** 후 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 압축을 푼 `KU-LMS-Plus` 폴더를 선택합니다.
5. 주소창 오른쪽 퍼즐 아이콘에서 **KU LMS+ 캘린더**를 고정해 두면 편합니다.

압축을 푼 폴더를 지우면 확장 프로그램도 같이 사라지니, 지우지 말고 그대로 두세요.

## 사용법

1. 크롬에서 LMS에 로그인합니다.
2. 툴바의 달력 아이콘을 누르면 캘린더가 새 탭으로 열립니다.

- 일정을 누르면 해당 LMS 페이지가 열립니다.
- 왼쪽에서 과목과 표시할 항목을 골라 볼 수 있습니다.
- **"온라인 강의 기간을 불러오지 못했습니다"**라는 안내가 뜨면, LMS에서 아무 강의실이나 들어가 왼쪽 메뉴의 **출결현황**을 한 번 연 뒤 캘린더의 **새로고침**을 누르세요.

## 업데이트

새 zip 파일을 받아 기존 `KU-LMS-Plus` 폴더의 내용을 바꾼 뒤, `chrome://extensions`에서 이 확장의 새로고침(↻) 버튼을 누르세요.

## 개인정보

불러온 정보는 내 브라우저 안에만 저장되고, 다른 서버로 보내지 않습니다. 로그인 정보도 따로 저장하지 않고, LMS에 로그인된 크롬의 상태를 그대로 사용합니다.
